# App Hub

A personal collection of browser-based tools, hosted on GitHub Pages.

## Apps
- 🎨 **Colour Converter** — Convert between Hex, 8-bit, and 10-bit RGB
- 📺 **Test Pattern** — Projector alignment pattern generator with PNG export
- 🖼️ **Slide Export** — Create and export presentation slides as PNG

## Hosting on GitHub Pages

### 1. Create a repository
- Go to https://github.com/new
- Name it `app-hub` (or anything you like)
- Set it to **Public**
- Click **Create repository**

### 2. Upload these files
- On the new repo page click **"uploading an existing file"**
- Drag and drop the contents of this zip (not the zip itself)
- Make sure `index.html` and `.nojekyll` are at the **root** of the repo
- Commit the files

### 3. Enable GitHub Pages
- Go to your repo → **Settings** → **Pages**
- Source: **Deploy from a branch**
- Branch: `main`, folder: `/ (root)`
- Click **Save**

### 4. Your site will be live at:
```
https://YOUR-USERNAME.github.io/app-hub/
```
Takes about 1 minute the first time.

## Updating
Edit `index.html` directly on GitHub.com using the ✏️ pencil icon,
or push changes via Git — the site rebuilds automatically.
