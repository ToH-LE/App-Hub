# App Hub

> Browser-based tools for live event and broadcast production.  
> Open the page. Everything works. Nothing to install.

---

## Tools

| | |
|---|---|
| 🎨 | **Colour Converter** — Convert between Hex, 8-bit RGB (0–255), and 10-bit RGB (0–1023). Type in any field and the rest update instantly. |
| 📐 | **Test Pattern** — Generate a projector alignment pattern with adjustable grid, crosshair, circles, border, and text overlay. Export as PNG at any resolution. |
| 🔭 | **Lens Calc** — Work out throw distance and lens requirements from screen width and throw ratio. |
| 🖼️ | **Slide Export** — Build title cards in the browser. Choose a layout, enter text, export as PNG or batch-download a ZIP. |
| ➗ | **Ratio Calc** — Simplify a ratio to lowest terms (1920:1080 → 16:9) or solve for a missing value in a proportion. |
| 📺 | **Format Calc** — CVT timing calculator for the Barco E2 and S3. Get full timing parameters and live connector compatibility. |
| 🎬 | **ATEM Calc** — Convert pixel positions to ATEM SuperSource box values (X, Y, Size, Crop) and back. Includes a crop solver and four-box layout planner. |

---

*All tools run entirely in the browser — no data is sent anywhere.*
